# Screenshots

Put the app screenshots used by the main README here. The README expects these file names:

| File | Content |
|---|---|
| `home.png` | Home screen with the animated title |
| `game.png` | A question in progress (portrait) |
| `game-over.png` | Game-over screen, ideally showing "New record!" |
| `history.png` | List of past games |
| `game-details.png` | Details of a game with ✓ / ✗ answers |
| `game-landscape.png` | A question in landscape |

Tips: capture them from the Android Studio emulator (camera icon in the emulator toolbar) at around 1080×2400, and optionally add a short `demo.gif` of a full game.
